## وضعیت دیتابیس
جداول ساخته شده: profiles (با نقش‌ها و دسترسی‌های JSONB)، stores، products، orders، order_items، reviews.
تمام قوانین RLS اعمال شده‌اند. تریگر `on_auth_user_created` برای ساخت خودکار پروفایل هنگام ثبت‌نام فعال است.

- سبد خرید مستقل برای هر غرفه (با استفاده از localStorage).
