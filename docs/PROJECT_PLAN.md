# نقشه راه پروژه بازار متل قو

## هدف پروژه
ساخت یک بازارگاه چندفروشندگی (Marketplace) که در آن هر فروشنده غرفه اختصاصی خود را دارد. قانون طلایی: سبد خرید، سفارش و پرداخت برای هر غرفه کاملاً مستقل است.
